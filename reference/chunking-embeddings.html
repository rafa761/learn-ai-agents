§2Chunking strategies (book §16.4)

StrategyMechanismUse when
Fixed-size + overlapWindow of W units stepping by W−O; boundary-agnosticDefault baseline; homogeneous prose. Our chunkWords()

A chunk must be (1) small enough for the embedding window, (2) semantically coherent, (3) self-sufficient when retrieved alone. Miss one and either retrieval or generation pays.

§4The chunker, LangChain → TypeScript

Listing 16.2 translated — the whole core in 9 lines
function chunkWords(text: string, size: number, overlap: number) {
  if (overlap >= size) throw new Error("overlap must be smaller than size");
  const words = text.split(/\s+/).filter(Boolean);
  const step = size − overlap;
  const out: string[] = [];
  for (let start = 0; start < words.length; start += step) {
    const window = words.slice(start, start + size);
    if (window.length === 0) break;
    out.push(window.join(" "));
    if (start + size >= words.length) break; // window covered the tail
  }
  return out;
}

§5Embeddings — what, which, how

An embedding is a dense vector whose direction encodes meaning (MiniLM: 384 dims; OpenAI text-embedding-3-large: 3072). Similar texts → small angle → cosine near 1; unrelated ≈ 0; there is no “opposite text” in practice, so real scores live in ≈ 0.0–0.6. The embedding model is the single most impactful component choice in a RAG system — it sets the quality ceiling for retrieval (book §16.9.1). Vectors from different models are not comparable: mixing them corrupts the space.

local, free, offline after first download — the lab stack
import { pipeline } from "@huggingface/transformers";
const embed = await pipeline("feature-extraction", "Xenova/all-MiniLM-L6-v2");
const tensor = await embed(text, { pooling: "mean", normalize: true });
// normalize: true → unit length → cosine degenerates to a plain dot product.
